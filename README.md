# Оценка изменения цены премиальной подписки

## О проекте

Проект посвящён анализу A/B-теста в дейтинговом приложении и оценке влияния изменения цены премиальной подписки на монетизацию продукта.

## Цель

Проверить, как изменение стоимости премиальной подписки повлияло на конверсию в оплату и ARPU.

## Стек

- Python
- pandas
- NumPy
- SciPy
- Matplotlib
- Jupyter Notebook

## Что сделал

- Проверил и объединил данные из 6 файлов.
- Проанализировал **12 911 пользователей**.
- Сравнил тестовую группу с двумя контрольными группами.
- Рассчитал ARPU и конверсию в оплату.
- Провёл статистическую проверку различий между группами.
- Учёл проблему множественных сравнений.
- Проверил устойчивость выводов при разных способах обработки спорных платежей.

## Результат

При сравнении тестовой группы с объединённым контролем конверсия в оплату снизилась с **4,39% до 3,39%**.

После поправки на множественные проверки снижение конверсии осталось статистически значимым. При этом статистически значимого роста ARPU обнаружено не было.

По результатам анализа рекомендовано **не внедрять изменение цены премиальной подписки**.

## Описание файлов

- `dating_app_ab_test.ipynb` — основной блокнот с обработкой данных и анализом результатов A/B-теста;
- `data/Проект_3_transactions_control_1.csv` — транзакции первой контрольной группы;
- `data/Проект_3_transactions_control_2.csv` — транзакции второй контрольной группы;
- `data/Проект_3_transactions_test.csv` — транзакции тестовой группы;

- `data/Проект_3_users_test.csv` — пользователи тестовой группы.
